# UPI Payment Failure Analytics — Product Case Study

## Problem Statement
UPI processes 600M+ transactions daily in India, yet failure rates 
reach 10–15% on certain corridors (first-time users, specific bank-merchant 
pairs, peak-hour loads). When a payment fails, users see a generic error 
screen with no actionable guidance — leading to drop-off, support tickets, 
and lost GMV.

This project simulates the work of a PM on Razorpay/PhonePe's 
payments reliability team: diagnosing failure patterns through data, 
understanding user pain through research, and designing a product 
intervention to measurably improve payment success rate (PSR).
